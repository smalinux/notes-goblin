takeaways

  • * means "address". Without it gdb treats main as a function and skips the prologue.
  • The skip size isn't fixed: sub rsp,N, stack canary setup or endbr64 make it bigger, and with -O2/no frame pointer it can be 0.
  • start = temporary b main + run → it also stops after the prologue.
  • For exploit work (stack alignment, what ret just landed on) always use b *addr.
