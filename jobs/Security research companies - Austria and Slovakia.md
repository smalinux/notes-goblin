# Security research / malware analysis companies — Austria & Slovakia

Live search 2026-09-27. ⭐ = best fit for malware analysis / security research.

## Austria

### Malware / product vendors (core RE work)
- ⭐ [IKARUS Security Software](https://www.ikarussecurity.com/en/) — Vienna. Austrian antivirus pioneer, own malware scan engine. Closest thing to a "VirusLab" job in Austria.
- ⭐ [Kaspersky](https://www.nucamp.co/blog/coding-bootcamp-austria-aut-top-cybersecurity-employers-in-austria-whos-hiring-and-what-they-look-for) — Vienna office (malware analysis, incident response roles).
- Nimbusec (Linz) — website malware monitoring, works with IKARUS engine.
- cyan Security Group — Vienna, threat protection products.
- CyberTrap — Vienna, deception technology.

### Research institutes (security research)
- ⭐ [SBA Research](https://www.cybersecurityintelligence.com/location/austria/) — Vienna. Austria's main IT-security research center. Hires researchers, offers PhD tracks.
- ⭐ AIT Austrian Institute of Technology — Vienna, cyber range + threat intelligence research.
- TU Wien / Uni Wien security groups — academic security research.

### Consulting / pentest / DFIR
- ⭐ [SEC Consult](https://sec-consult.com/career/) — Vienna HQ, part of Atos. Vulnerability research lab, big name in EU.
- Certitude Consulting — Vienna, known for public vulnerability research.
- Hackner Security Intelligence, Syslifters, VidraSec, SecCore, Strong-IT, RootSys — smaller pentest shops ([list](https://slashsec.at/en/docs/pentesting-austria)).
- TÜV TRUST IT, Pentest Factory — audits + pentesting.
- Big 4 (KPMG, Deloitte, PwC, EY) — all have cyber/IR teams in Vienna.

### SOC / MDR / enterprise
- [CANCOM Austria](https://freehire.me/jobs/cyber-security-defense-analyst-w-m-cancom-austria-ag-dd46qsgt) (ex-Kapsch) — Cyber Defense Center, Vienna, ~€60k start for defense analyst.
- [A1 Telekom Austria](https://isecjobs.com/job/777692-cyber-security-analystin-wmd/) — SOC/CERT, hiring cyber security analysts now.
- T-Systems Austria, Cisco Vienna, IXOLIT.
- Banks: Raiffeisen Bank International, Erste Group, BAWAG — internal SOC/threat intel teams.

### Gov / international (Vienna is special here)
- CERT.at / GovCERT Austria — national CERT.
- ⭐ [IAEA](https://unjobs.org/vacancies/1782834432479) — UN, hires cyber security operations staff in Vienna. Also OSCE, UNODC, OPEC Fund.

## Slovakia

### Malware / product vendors
- ⭐ [ESET](https://en.wikipedia.org/wiki/ESET) — Bratislava HQ + Košice office. VirusLab actively hiring malware analysts (reverse engineering, tooling, threat intel). #1 target in Slovakia.
- Excalibur — MFA/security products.
- SaferPass, Byte Pioneers — smaller product startups.

### DFIR / threat intel / pentest
- ⭐ [IstroSec](https://sk.linkedin.com/company/istrosec) — Bratislava, founded by ex-ESET researchers. DFIR + threat research (co-reported Russian APT vs Slovak gov).
- ⭐ [Binary Confidence](https://www.binaryconfidence.com/en/) — SOC-as-a-service + incident response; posts SOC analyst openings.
- [Citadelo](https://citadelo.com/en) — Bratislava/Prague/Switzerland, ethical hacking / pentest.
- [Nethemba](https://techbehemoths.com/companies/cybersecurity/slovakia) — web app security, pentest, forensics.

### SOC / enterprise
- [Void SOC (Soitron)](https://voidsoc.com/en/home/) — 24/7 SOC, Bratislava.
- ⭐ [Deutsche Telekom IT Solutions Slovakia](https://careers.smartrecruiters.com/deutschetelekomitsolutionsslovakia) — Košice, ~3,900 staff. Many open roles: SIEM/SOC engineer, security engineer, detection rules.
- IBM Slovakia — Bratislava security center (consultants, analysts, IR).
- ANASOFT, Aliter Technologies, ALISON Slovakia, Decent Cybersecurity — infra/data protection.
- Guardians.sk — security services.

### Gov
- SK-CERT (NBÚ) + CSIRT.sk — national cyber units (may need Slovak citizenship/clearance).

## Takeaway
- Pure malware analysis: ESET (Bratislava, biggest + best), IKARUS + Kaspersky (Vienna), IstroSec.
- Rest = SOC / pentest / consulting. Nearby work, not RE-focused.
- Bratislava ↔ Vienna ≈ 1h. Both markets reachable from either city.
