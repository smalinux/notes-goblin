# Level-Up Directions 🧭

Ten project-driven directions to get deeper into RE, malware analysis, and assembly — each built on one principle: **pick a target you care about and let it drag the theory out of you on demand.** Every plan maps to the 29-skill [re-roadmap](../re-roadmap.html), plays to your strengths (Linux kernel, C, OS internals, ARM, chess-brain), and ends in an artifact for your portfolio.

Pick **one** to be the main quest. Run a second as a light side-quest if you want variety. Don't start more than two — the whole point is a single goal to aim at.

| # | Direction | Best if you want… |
|---|-----------|-------------------|
| 01 | [Linux Kernel Rootkit RE & Defense](01-kernel-rootkit-re.md) | to weaponize your biggest edge (kernel + C) |
| 02 | [The Chess-Player's CTF Ladder](02-ctf-ladder.md) | competitive, ranked puzzle-solving |
| 03 | [Firmware & IoT / Router RE](03-firmware-iot-re.md) | a physical device you fully own (uses ARM) |
| 04 | [RE Toolsmith — Build the Tools](04-re-toolsmith.md) | to learn RE by building it in C |
| 05 | [Malware Analysis, 0 → Analyst](05-malware-analyst-track.md) | the job-ready malware curriculum |
| 06 | [Vulnerability Research & Exploit Dev](06-vuln-research-exploit-dev.md) | the highest-ceiling 0-day path |
| 07 | [The Anti-Analysis Arms Race](07-anti-analysis-arms-race.md) | the cat-and-mouse game, both sides |
| 08 | [Automated RE — Emulation & Symbolic Exec](08-automated-re-emulation-symbolic.md) | to make a machine solve it for you |
| 09 | [Master Assembly via the Compiler](09-assembly-via-compiler.md) | to actually get fluent in assembly |
| 10 | [Learn by Teaching — Crackmes & Writeups](10-learn-by-teaching.md) | to turn curating into mastery + portfolio |

See also: [the Tibia + Malware plan](../tibia-malware-learning-plan.md) — the dream-game direction.

**The one rule across all of them:** every session ends with an artifact that didn't exist before — a solved crackme, a reconstructed struct, a fuzzer crash, a published writeup. Consuming is what bored you; producing is the fuel.
